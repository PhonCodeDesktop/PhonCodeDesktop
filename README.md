### 🚀 Proyectos & Construcciones

| 🛠️ Proyecto | 📝 Descripción | ⚙️ Stack | 📌 Estado |
| :--- | :--- | :--- | :--- |
| **ControlTaller** | Gestión de servicio técnico: órdenes, stock, finanzas y flyers. | `Tauri` `React` `SQLite` | `Activo` |
| **MiLauncher2** | Launcher y lockscreen para Android con estética tipo terminal y shaders. | `Kotlin` `XML` `Android` | `En desarrollo` |
| **Tactical FPS** | Shooter táctico en primera persona con rondas, compra y mecánicas de objetivo. | `Godot` `C#` | `Prototipo` |
| **PCGameCheck** | Utilidad de escritorio que escanea hardware y evalúa compatibilidad con juegos. | `Python` | `Listo` |
| **NanoChat** | Cliente de chat de escritorio en tiempo real con comunicación multijugador. | `React` `Electron` `Socket.IO` | `Iterando` |

### 🧪 En el Lab & Enfoque

* 🖥️ **UIs con identidad:** Interfaces oscuras, estilo terminal/HUD, transiciones limpias y launchers o entornos propios.
* ⚙️ **Sistemas & Desktop:** Herramientas rápidas, útiles y bien estructuradas para el día a día.
* 🎮 **Game Dev & Shaders:** Experimentando con mecánicas, físicas, shaders y flujo de juego.
* 🐧 **Entorno Linux & Customización:** Ajuste fino del sistema, flujos de trabajo en terminal y configuración a medida.
